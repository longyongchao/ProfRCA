# 可选的原生答案空间

本分支在统一方法入口新增/完善可选的 `label_space` 支持。默认开放类别提示词与既有30机制协议保持可用。
自定义字典包含 `category: {ID: 一级类别}`、`prompt`（完整候选定义），可提供 `descriptions: {ID: 定义}`。

- 直接 LLM 将完整候选定义放入系统提示，保留日志和指标全文。
- D-Bot 各角色均看到相同候选定义；专家搜索、反思、投票和交叉复核不变。最后格式化仅可将报告已明确的根因转换为候选ID，不能新增诊断。
- RCA-Agent 在候选原因列表中展示完整ID及定义，隔离执行器和控制循环不变。
- ProfRCA 指标工具使用训练时的 `label_info` 输出原生ID，通用回退分支使用该候选提示。

同一类别可以有多个不同ID。无效ID不会由模糊匹配自动变成正确标签，由外部评分器计错。不能从单个测试案例的金标准构建候选集合，根因数量不传入诊断。

这属于封闭答案协议适配，不能将其结果直接称为原开放答案论文复现。D-Bot的离线知识/工具差异仍见 `SOURCE_PROVENANCE.md`。
